# 文档维护约定

所有本项目工作、审计材料和生成文件均放在本仓库内，不在上级目录创建工作目录。
在 Windows PowerShell 中读取中文文件时显式使用 `-Encoding UTF8`。

README 只记录项目定位、概况与文档入口；其余文档统一放在 `docs/`。
运行手册按“运行方面的指令”和“查询方面的指令”两节组织，记录服务器命令及必要用法。
版本控制、仓库选取、配置与数据口径维护在 `项目元数据.md`；需求及实现说明维护在
`需求说明.md`；本地模型准备与历史审计分别使用对应文档和 `audits/`。
新增代码可按职责放入独立目录，文档变更须同步检查链接，并区分当前实现、未来计划与历史记录。
