# 相关方面与情感比例：规划用初步估计

日期：2026-09-14。

## 主要结果

这是助手对原文的语义复核估计，不是人工金标准，不可作为论文最终真实比例。估计对象是现有 v7 成功标注的 96,258 条：它们属于按仓库设上限且输入不超过 4,000 字符的 clean-v1 样本，不能直接推广到全部 GitHub 或全库原始语料。

| 口径 | 加权点估计 | 只考虑抽样误差的约95%区间 | 建议规划范围 |
|---|---:|---:|---:|
| 实质涉及至少一个既定方面，含 neutral | 37.5% | 30.3%–44.9% | 30%–45% |
| 至少一个方面有明确正面或负面评价/体验 | 22.3% | 16.5%–29.1% | 15%–30%，中心按20%–25% |

规划范围做了粗粒度取整，依然不能覆盖所有标注定义与判断误差。不要把百分数理解成统计保证。尤其我采用了“实质事实/问题/建议可以有方面，正负情感另判断”的口径；这是对 v7 部分标签必须明确评价的门槛的澄清，并非宣称严格照搬 v7 每一句就应达到该比例。

## 怎么得到的

此前随机抽查了1,500条。为保留原来的500条盲标材料，本次从其余1,000条（v7非空59、空941）再分层抽取：v7判空200条、非空50条。种子2026091302。250条混合打乱后，显示的输入不含原v7标签，逐条给出核心判断、边界候选和理由；部分文本曾在前一轮审计出现，因此不能称为独立双盲。

| 原v7分层 | 本次复核数 | 有核心方面依据 | 有核心正负情感依据 |
|---|---:|---:|---:|
| 空数组 | 200 | 68 | 37 |
| 非空 | 50 | 50 | 45 |

总体v7非空占比 q=5,069/96,258=5.266%。

- 方面率 = q×(50/50) + (1−q)×(68/200) = 37.48%。
- 正负情感率 = q×(45/50) + (1−q)×(37/200) = 22.27%。

不能直接把118/250或82/250当总体比例，因为非空层被刻意多抽。这里检查的是“是否有任何方面/正负情感”，非空50/50不表示它们原来的具体方面和极性全部正确。

区间方法：分别对两层计算97.5% Wilson二项比例区间，用Bonferroni思路组合为约95%的同时范围，再用q加权端点。采用此法是为避免50/50时用简单正态方差得到虚假的零误差。二阶段抽样近似按层内随机抽样处理，区间没有纳入语义复核者偏差。
方法参考：[NIST 比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。

## 口径敏感性

核心规则：有实质信息的事实、问题、设计建议可标方面；仅符号、普通复现、机械状态不标。正负评价需可归于作者且与方面对应；不能把所有功能请求、编译失败或礼貌致谢当成情感。

若把所有边界候选一律纳入，方面率会达到55.95%、正负情感率34.90%。这两个数是敏感性极端，不是推荐估计，也不是统计上界。它们显示“普通功能问题、单次平台Bug、短回应、一般库推荐是否纳入”必须先形成清晰标注手册。后续应由独立标注者裁决这些边界。

本次250条没有核心community样本，learning_curve仅1条；其他罕见方面也只见到少数。不能根据小样本估计它们精确的总体比例或宣称为零。总体有20%左右正负情感，并不等于13方面×3极性都够训练。

## 对采集与标注决策的含义

按同样抽样分布每取10,000条，规划上可预期原文中约3,000–4,500条有方面信息，其中约1,500–3,000条有正负情感。这是可用信息的潜在数量，不是某个新版提示词一定能识别出的数量；实际产出还取决于精度、召回、去重和质量审核。

不建议现在全量重标96,000条，也不建议立刻只按词典到GitHub新增采集。建议顺序：

1. 固定标注口径，用原500条独立复核一部分开发样本，保留未用于调规则的测试部分，按父讨论串隔离；评估修改后提示词。
2. 若小规模评估确认召回改善且误标可接受，先随机重标现有库5,000–10,000条作为首批，以每方面/每极性实际支持数和学习曲线决定是否扩到20,000–30,000或更多。没有统一的样本数足够标准。
3. 同时对稀缺方面在现有库做词典/语义定向检索，再标注候选。词典只用来找候选，不能直接作为情感标签。社区、学习曲线等主题若本库召回后仍很稀缺，再定向补采外部来源。
4. 将随机样本与定向样本保留来源标记，真实比例估计和测试集继续使用随机抽样；不能从词典命中集计算全局情感率。

可把初期标注预算按60%–70%随机重标、30%–40%稀缺方面候选复核作一个可调整的起点；该比例是工程安排，不是实验已证明最优。更关键的是先查看每方面×极性的可用支持数，而非只追求总非空率。

词典应含语义短语而非仅名词。例如ownership可用借用/生命周期与困难、限制、简化等体验表达的组合，同时保留不带这些词的语义检索通道；community检索维护者响应、求助、治理与合作体验；learning_curve检索理解核心概念、入门和学习成本。新增数据需避免只命中负面词，导致情感分布偏斜。
词典与规则产生的是弱监督候选，而非天然正确标签，可参考[Snorkel原论文](https://vldb.org/pvldb/vol11/p269-ratner.pdf)。
