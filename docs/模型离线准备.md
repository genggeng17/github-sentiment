# 主题编码器的本地离线准备

本页记录无法在服务器下载模型时的本地操作，PowerShell 命令在本地仓库根目录执行。
服务器下载、验证和训练命令见 [运行手册](运行手册.md)。

镜像不可达时，在能访问 Hugging Face 官方站点的机器下载，再复制模型目录到服务器。以下 PowerShell 命令在本地仓库根目录执行；`allow_patterns` 只取本项目使用的 PyTorch safetensors 权重、配置和词表，避免下载该仓库的其他格式权重：

```powershell
python -m pip install -U huggingface_hub
python -c "from huggingface_hub import snapshot_download; snapshot_download('sentence-transformers/all-MiniLM-L6-v2', local_dir='data/models/all-MiniLM-L6-v2', allow_patterns=['*.json', '*.txt', '*.safetensors'])"
```

通过现有 SSH 连接传到服务器；将 `SERVER` 替换成实际可连接的主机名或 SSH 配置别名：

```powershell
ssh cyg@SERVER 'mkdir -p /opt/GITHUB-SENTIMENT/github-sentiment/data/models'
scp -r data/models/all-MiniLM-L6-v2 cyg@SERVER:/opt/GITHUB-SENTIMENT/github-sentiment/data/models/
```
